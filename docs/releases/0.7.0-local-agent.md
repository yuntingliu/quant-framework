# AlphaLab 0.7.0

This release integrates the bundled Conexus runtime from `deploy/local` with the
research, data-quality, authentication, and documentation improvements on `main`.

## Local Agent and provider setup

- `alphalab dev serve` starts the local Agent alongside the API. Build the pinned
  Conexus runtime first, following the [local deployment guide](../07_LOCAL_DEPLOYMENT.md).
- Open **Model providers** in the sidebar to save an API base URL, model ID,
  and API key, test the connection, and select the active profile.
- Provider changes apply to new runs. Existing runs retain their original
  provider. Keys are stored in the backend runtime directory and omitted from
  settings responses and browser storage.
- This adapter uses OpenAI-compatible Chat Completions with tool calling.
  Native Anthropic/Gemini and Responses-only endpoints require an adapter or gateway.
- Environment configuration and remote Conexus mode remain available.

## Integrated workstation

The application now lives in `apps/api` and `apps/desktop`. A research project
can contain multiple strategies under `strategies/`. Persistent application state
lives in `data/runtime/app` by default. Existing legacy databases are migrated
when no runtime database exists.

The merge preserves point-in-time financial checks, scoped RQ synchronization,
technical-evidence research, and market partition pruning from main. Maintained
documentation is English and does not depend on a particular deployment machine.

## Verification scope

Automated acceptance covers local startup, live provider activation, an Agent
tool invocation, report persistence, and restart recovery using a controlled
loopback model. The provider dialog was also exercised in the browser.

An external provider still requires a valid account key and a tool-capable model.
A successful connection test confirms a Chat Completions response; complete an
Agent request to confirm that provider's tool-calling behavior. See the
[deployment acceptance procedure](../08_LOCAL_DEPLOYMENT_VALIDATION.md).
