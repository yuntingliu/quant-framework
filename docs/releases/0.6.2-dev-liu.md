# AlphaLab 0.6.2 · dev_liu

修正质量因子财报转换，并通过当前 SDK v1 新跑七组股票级对照，覆盖2019与2020完整年度。
版本基于0.6.1，继续保留dongfang/dev_liu整合后的唯一策略执行链路。

原来的2020年4.46%来自20万元、100股整手账户，平均持仓34.17只、现金33.72%；
它不适合直接当作理论质量指数的复现结果。新的月度等权、历史沪深300前50只平均ROE
组合为2019年44.43%、2020年44.31%，讲义对应44.62%、42.64%。同规则全A股为
19.97%、18.40%，说明本次对照中的股票池差异很大。

| 改动 | 行为 |
|---|---|
| 财报可见时间 | 原始披露至少下一日可用；不接受只有调整后记录的季度充当原始版本 |
| TTM与ROE | 精确季度匹配，检查依赖披露日期；ROE使用本期与去年同期平均正净资产 |
| ROA与诊断字段 | 增加平均总资产代理、期末净资产ROE和TTM利润等可追溯字段 |
| 质量因子模板 | 新增ROE、ROA与低杠杆排名均值；缺失或无穷输入剔除 |
| 复现实验 | 冻结本地缓存，经规范项目保存API运行七组固定对照，保存每日权重与成交 |
| 大样本性能 | SDK仅对所需字段和有效末尾窗口透视，稀疏历史语义保持一致 |

复现仍属透明代理：讲义未给出质量指数代码、精确样本和调仓方法。本次只新跑2019–2020，
没有重跑全部11年，也没有样本外或机器学习增益证据。新结果采用比例权重，含比例佣金和
滑点，不含100股整手、最低佣金及印花税独立账本；历史成分是月度快照，涨跌停价由保存的
策略规则估计补齐。不能将44.31%称为20万元实盘账户收益或精确复现。

命令和输入约定见 `docs/06_ALPHALAB_SDK_GUIDE.md`。完整实验表、旧账户诊断、快照哈希、
七组输出与报告作为交付包research附件提供；本地行情和生成研究产物不进入源码git。
本版本只在本地dev_liu提交，未推送远程。
