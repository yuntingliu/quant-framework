# AlphaLab 0.6.1 · dev_liu

本版本基于 0.6.0 的 dongfang / dev_liu 整合提交 `b8e8180`，在本地 `dev_liu`
继续开发。保留 SDK v1 唯一策略执行链路。

- 增加带日期、币种、价格口径、成交量单位、来源和输入指纹的技术证据计算。
  支持均线、收益、MACD、RSI、KDJ、TR/ATR、布林带、CCI、OBV 和显式形态条件；
  历史不足、未提供基准和未核对交易日历会直接披露。
- 现有因子目录增加下影线收回、三连阳实体形态和放量突破三个 SDK 原生模板。
  它们是研究筛选条件，尚未证明能提高样本外净收益。
- 增加年度收益复算工具，区分复合累计收益、按实际年份计算的 CAGR 和跑赢基准年份占比。
- 提供技术证据复盘、因子复现审计两个可安装 skills。命令与数据约定见 SDK 指南。

本次针对《第六章：多因子及 Barra 模型2026》第14页复算公开表格，并重新汇总之前
冻结的本地研究产物。讲义 2010–2020 是11年，公布年化与12年口径相符；复算表格
不等于独立股票回测。原研究的样本池、因子代理和组合规则未与讲义对齐，且已有质量
组合表现未重现讲义优势。成长、红利和讲义原始质量＋价值指数仍缺确切定义及对应数据。

SNOW 示例使用 2026-09-04 及之前47根公开日线核算；较长均线无法由该窗口验证，
递归指标存在初始化差异。报告不据 OBV 推断主力意图，也不输出未经历史检验的预测概率。

研究数据、生成报告、行情快照和测试日志位于忽略的 artifacts 目录；不纳入源码 git。
完整交付包另带研究附件和校验清单。此次未推送远程。
