# 研究流程参考笔记

本文件保留研究流程与评估思路；当前可执行 SDK 以
[AlphaLab SDK 指南](../06_ALPHALAB_SDK_GUIDE.md)为准。

一、研究阶段

1. 确定投资目标

首先确定策略边界：

股票池：沪深300、中证500或者全A；
模式：纯多头、指数增强或多空；
基准：沪深300等；
调仓频率：月度；
最大回撤、波动率目标；
单只股票和行业权重限制；
是否允许小盘股、ST、停牌和低流动性股票。

例如：

在沪深300中，通过价值、质量和动量因子选出50只股票，每月调仓，控制行业偏离和换手率。

2. 准备 point-in-time 数据

每个历史时点只能使用当时已经公开的信息，包括：

行情和成交量；
财报实际发布日期；
当时的指数成分股；
停牌、ST、退市记录；
行业分类；
交易成本和涨跌停限制。

不能用后来修订的数据，也不能假设财报期结束当天就已经知道财报内容。

8. 制定组合规则并回测

例如冻结以下规则：

综合排名前50进入候选；
已持有股票跌出前70才卖出；
单只股票上限3%；
单行业相对基准偏离不超过5%；
月度换手率不超过30%；
下月首个交易日 VWAP 执行；
计入佣金、冲击成本和涨跌停。

最后使用训练集、验证集和完全未使用的测试集进行检验。确定规则后，应尽量避免根据测试结果继续反复修改。

四、运行后要做什么？

每个月需要进行收益归因：

PortfolioReturn=FactorReturn+StockSpecificReturn−TradingCost

检查：

收益究竟来自 Value、Quality 还是 Momentum；
是否其实来自行业或小盘暴露；
实际成交与目标组合偏差；
换手和冲击成本；
IC 是否开始衰减；
风险和回撤是否超过预设范围。

如果一个月表现差，通常不应立即修改策略。只有在累计证据显示：

因子经济逻辑失效；
样本外 IC 持续恶化；
交易成本结构改变；
数据或执行出现错误；

时，才进入新的研究版本。不能一边交易一边根据最近收益随意改参数。

一套具体月度模板
时间    工作
月末收盘后    更新数据、计算因子、生成分数
当晚    生成目标名单和目标权重
下月首个交易日    买卖新旧权重差额
月中    持有、监控风险和公司事件
下一个月末    重新计算并调仓
每季度    做归因和稳定性评估
参数失效且证据充分时    重新研究，而非临时改策略

最终可以把整个系统概括成：

经济假设→因子→股票评分→预期收益→目标权重→交易订单→持仓监控→下次调仓
    ​

其中，“研究组合”用于证明因子有效，“实际投资组合”用于在风险、成本和交易约束下获取因子收益；两者通常不是完全相同的组合。
